# نظام إدارة حضانة وتخاطب — مربوط بـ Firebase Realtime Database

تطبيق ويب واحد (HTML/CSS/JS بدون أي أدوات بناء) بيستخدم:
- **Firebase Authentication** (بريد إلكتروني + كلمة مرور) لتسجيل الدخول.
- **Firebase Realtime Database** لتخزين ومزامنة كل البيانات لحظيًا بين كل المستخدمين.

## الملفات
- `index.html` — هيكل الصفحة
- `style.css` — التصميم
- `app.js` — كل منطق التطبيق
- `firebase-config.js` — إعدادات مشروعك على فايربيز (لازم تعدّلها)
- `database.rules.json` — قواعد الحماية (Security Rules) الجاهزة للاستخدام

## خطوات الربط بفايربيز

### 1) إنشاء مشروع
اذهب إلى [console.firebase.google.com](https://console.firebase.google.com) → **Add project** → اختار اسم المشروع.

### 2) تفعيل Authentication
من القائمة الجانبية: **Build → Authentication → Get started** → فعّل **Email/Password**.

### 3) تفعيل Realtime Database
من القائمة الجانبية: **Build → Realtime Database → Create Database** → اختار المنطقة → ابدأ في **وضع الاختبار locked mode** (هنستبدل القواعد بعدين).

### 4) نسخ إعدادات المشروع
من **⚙️ Project settings → General → Your apps** → اضغط أيقونة الويب `</>` لإنشاء تطبيق ويب → هتظهر لك بيانات زي دي:

```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  databaseURL: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "...",
};
```

انسخها كلها والصقها مكان القيم في ملف `firebase-config.js` (مهم جدًا حقل `databaseURL` بالذات لأنه بيحدد Realtime Database).

### 5) رفع قواعد الحماية
من **Realtime Database → Rules** انسخ محتوى ملف `database.rules.json` والصقه هناك واضغط **Publish**.

هذه القواعد بتضمن:
- محدش يقدر يقرأ أو يكتب غير وهو مسجّل دخول.
- الأدمن بس يقدر يغيّر أدوار وصلاحيات المستخدمين.
- أي عملية إضافة/تعديل على الأطفال، المتابعين، التقدم، الخطط، أو التقارير محتاجة الصلاحية المناسبة المسجّلة في بروفايل المستخدم.

### 6) تشغيل الموقع
لازم تشغّله عن طريق سيرفر محلي (مش بفتح الملف مباشرة من الجهاز) عشان الـ ES Modules تشتغل صح، مثلًا:

```bash
npx serve .
```

أو ارفع المجلد على **Firebase Hosting** مباشرة:
```bash
npm install -g firebase-tools
firebase login
firebase init hosting   # اختار نفس المشروع، والمجلد الحالي كـ public directory
firebase deploy
```

## أول استخدام
- أول حساب هتعمله بـ "حساب جديد" هيتحول تلقائيًا لـ **مدير النظام (Admin)**.
- أي حساب تاني هيتسجل بعده هيفضل **بانتظار التفعيل** لحد ما الأدمن يدخل على **المستخدمون والصلاحيات** ويحدد له الدور (مدير حضانة / مشرف / أخصائي تخاطب) ويعدّل صلاحياته لو حابب.

## الأدوار الافتراضية
| الدور | الصلاحيات الافتراضية |
|---|---|
| مدير النظام (Admin) | كل شيء، بما فيها إدارة المستخدمين |
| مدير الحضانة | إدارة الأطفال، المتابعين، التقدم، الخطط، التقارير |
| مشرف | تسجيل التقدم، الخطط، التقارير |
| أخصائي تخاطب | تسجيل التقدم، التقارير |

الأدمن يقدر يعدّل أي صلاحية لأي مستخدم يدويًا من نفس الشاشة بعد اختيار الدور.

## ملاحظة
لو عايز تحذف بيانات تجريبية أو تعمل نسخة احتياطية، هتلاقيها في **Realtime Database → Data** في الكونسول، على شكل JSON تحت العناوين: `users`, `children`, `assignments`, `milestones`, `plans`, `reports`.
